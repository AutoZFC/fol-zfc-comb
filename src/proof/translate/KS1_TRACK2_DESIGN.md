## 0. The pieces, and which paper result builds each

The end-to-end claim is **Thm 19**: combinatorial proofs `φ : C → A` are
exactly the images of decomposed KS1 derivations. We implement the
**KS1 → comb** direction (read a comb proof off a KS1 derivation); the
converse (comb → KS1) is the soundness/completeness witness and is useful as
a test oracle but not on the critical path.

```
   KS1 derivation  Φ : t ⟶ A          (cut-free; A = goal in NNF)
        │  Thm 17  (decomposition)
        ▼
   t ──MLS1^X──▶ A'  ──{w,w∀,ac,c∀,m,m∨,m∃,≡}──▶ A
        Φ1  (linear core)        Φ2  (resource: contraction + weakening)
        │                                  │
        │ Thm 33: [[Φ̂1]] = ⟨[[Â']],∼Φ̂1⟩    │ Lemma 41: ⌊Φ̂2⌋ : [[Â']] → [[A]]
        │   is a FONET, δΦ1 a dualizer      │   is a SKEW BIFIBRATION
        ▼                                  ▼
        └──────────▶  CombProof  φ : C → [[A]],  C = [[Â']]  ◀──────────┘
                       (fonet = source, skew bifibration = fibration)
```

So the bridge is literally: **decompose, read the fonet off the linear core's
`ai`-pairs and `∃`-instantiations, read the skew bifibration off the resource
phase's induced vertex map.** Both halves are existing comb structures
(`comb_proof.h`: `Fonet`, `fibration`, dualizer).

## 1. Syntax KS1 operates on (§II-A)

Same first-order language as the rest of the codebase, in **negation normal
form**. Fix disjoint countable VAR, FUN (with arities), PRED (with arities).
Each predicate `p` has a **dual** `p̄ ≠ p`.

```
  t ::= x | f(t1,…,tn)                          terms
  a ::= t | f | p(t1,…,tn) | p̄(t1,…,tn)         atoms   (t = ⊤, f = ⊥)
  A ::= a | A ∧ A | A ∨ A | ∃x.A | ∀x.A         formulas
```

Negation `(·̄)` is defined on atoms/formulas by De Morgan (so formulas are
*always* in NNF; there is no `¬` connective node):

```
  t̄ = f      p(…)‾ = p̄(…)      (∃x.A)‾ = ∀x.Ā      (A∧B)‾ = Ā ∨ B̄
  f̄ = t      p̄(…)‾ = p(…)      (∀x.A)‾ = ∃x.Ā      (A∨B)‾ = Ā ∧ B̄
```

`A ⇒ B` abbreviates `Ā ∨ B`. **Rectified** = all bound variables distinct from
each other and from all free variables (α-convert to achieve; the rectified
form `Â` is unique up to renaming). Several KS1 results require rectified
formulas/derivations.

Our `core/formula.h` already stores NNF-ish formulas with `Op::{And,Or,Forall,
Exists,Bottom}` and De Bruijn indices. **Representation note:** KS1 needs `t`
(⊤) as a first-class unit and explicit `f` (⊥). We have `Bottom`; `t` is
encoded in the comb layer as `¬⊥` / the `One` vertex (`VertexKind::One`). The
KS1 module will need a units-aware formula view — decide in Phase 1 whether to
reuse `core::Formula` with a `One` convention or wrap it.

## 2. Equivalence `≡` (§II, eq (2))

`≡` is the congruence generated by (on **rectified** formulas), verified
verbatim against the paper text (`pdftotext` of p.4, not the figure OCR):

```
  A ∧ B ≡ B ∧ A            (A ∧ B) ∧ C ≡ A ∧ (B ∧ C)
  A ∨ B ≡ B ∨ A            (A ∨ B) ∨ C ≡ A ∨ (B ∨ C)
  ∀x.∀y.A ≡ ∀y.∀x.A        ∀x.(A ∨ B) ≡ (∀x.A) ∨ B     (x not free in B)
  ∃x.∃y.A ≡ ∃y.∃x.A        ∃x.(A ∧ B) ≡ (∃x.A) ∧ B     (x not free in B)
```

> **Math correction (2026-05-21).** An earlier draft of this doc paired the
> distribution equations the wrong way (`∀` over `∧`, `∃` over `∨`) — an OCR
> error off Fig. 3's render. The correct pairing is **`∀` distributes over
> `∨`, `∃` over `∧`**, forced by the fograph semantics: `[[∀x.A]] = •x + [[A]]`
> with `∨ = +`, so `[[∀x.(A∨B)]] = •x+([[A]]+[[B]]) = (•x+[[A]])+[[B]] =
> [[(∀x.A)∨B]]`; dually `[[∃x.A]] = •x × [[A]]` with `∧ = ×`. The wrong pairing
> would violate Thm 8. Sanity-checked against the paper's Example 9:
> `∃x.(px ∨ ∀y.py) ≡ ∃x.∀y.(py ∨ px)` (push `∀y` out through the `∨` since
> `y ∉ px`). Distribution holds in either bracketing direction by
> commutativity (`B ∨ ∀x.A`, `B ∧ ∃x.A`).
**Thm 8:** for rectified `A,B`,  `A ≡ B  ⟺  [[A]] = [[B]]` (equal fographs).
This is what lets `≡`-steps be *invisible* in the comb read-off: they do not
change the fograph, so they contribute nothing to the fonet or fibration.

> **K1 finding (2026-05-21):** Thm 8 holds *semantically* (equal as graphs),
> but our `comb::Fograph` is **not a canonical representative** under vertex
> reordering — it stores a `labels`/`edges` vector whose order follows the
> construction recursion, and `≡` includes commutativity (`A∧B ≡ B∧A`), which
> permutes vertices. So two `≡`-equal formulas give **isomorphic but not
> struct-equal** fographs; raw `Fograph` equality is **not** a valid `≡` test.
> `Fograph` has no `operator==`/isomorphism today (checked `fograph.cpp`,
> `cotree.{h,cpp}`, `comb_proof.h`). Therefore **K1 implements `≡` as a
> normalize-modulo-eq(2) canonicalizer** on the formula (flatten ∧/∨
> associativity, sort commutative operands by a stable key, normalize adjacent
> same-quantifier and ∀/∃-over-∧ swaps), then structural equality on the
> normal form — not via the fograph. Graph isomorphism is the fallback if the
> canonical form proves awkward for the quantifier-shift equations.

## 3. Deep-inference contexts `S{·}` (§V)

A **context** `S{·}` is a formula with exactly one occurrence of a **hole**
`{·}` in atom position. `S{A}` plugs `A` into the hole. A deep-inference rule
`r : P / Q` (premise over conclusion) applies *inside any context*: from
`S{P}` derive `S{Q}`. This is the one structural primitive the whole system
needs; everything else is the rule table.

**Representation decision (Phase 1):** a context is a formula-with-a-marked-
node, i.e. a path from the root to the hole. A `DerivationStep` is
`(rule, context_path, instantiation_data)`; applying it rewrites the node at
`context_path` from the rule's redex to its contractum. A `Derivation` is a
top formula `t` (or general top `B`) plus an ordered list of steps producing
the bottom formula `A`. The checker replays steps and checks each is a valid
instance of its rule in its context.

## 4. The system KS1 (Fig. 6)

`P / Q` = premise over conclusion (read top-down: from `P` infer `Q`). All
rules fire inside a context `S{·}`. The **dashed-box** subsystem is
**MLS1^X** (multiplicative linear + mix); the rest is the resource fragment.

### 4.1 MLS1^X — linear core (dashed box)

| rule | schema `S{P} / S{Q}` | note |
|------|----------------------|------|
| `∀`  | `S{t} / S{∀x.t}` | introduce vacuous universal over ⊤ |
| `ai` | `S{t} / S{a ∨ ā}` | atomic interaction (identity) — **these are the fonet links** |
| `t`  | `S{A} / S{A ∧ t}` | unit |
| `s`  | `S{A ∧ (B ∨ C)} / S{(A ∧ B) ∨ C}` | switch (the linear distributor) |
| `mix`| `S{A ∧ B} / S{A ∨ B}` | mix |
| `∃`  | `S{A[x/t]} / S{∃x.A}` | instantiation — **these define the dualizer** δ |
| `≡`  | `S{B} / S{A}` where `A ≡ B` | equivalence (eq (2)) |

### 4.2 Resource fragment — contraction & weakening (outside the box)

| rule | schema `S{P} / S{Q}` | note |
|------|----------------------|------|
| `w`  | `S{A} / S{A ∨ B}` | weakening |
| `w∀` | `S{A} / S{∀x.A}`  (x not free in A) | universal weakening |
| `ac` | `S{a ∨ a} / S{a}` | **atomic** contraction |
| `c∀` | `S{∀x.∀x.A} / S{∀x.A}` | binder contraction — see note ⚠ |
| `m`  | `S{(A∧C) ∨ (B∧D)} / S{(A∨B) ∧ (C∨D)}` | medial |
| `m∨` | `S{(∀x.A) ∨ (∀x.B)} / S{∀x.(A∨B)}` | medial for ∀ |
| `m∃` | `S{(∃x.A) ∨ (∃x.B)} / S{∃x.(A∨B)}` | medial for ∃ |

> ⚠ **`c∀` schema is OCR-uncertain.** Fig. 6 rendered its premise and
> conclusion identically in the extracted image. The **authoritative** form is
> the *rectified* `c̃∀` from §IX:  `S{∀y.∀x.Ax} / S{∀x.Ax}`  (contract two
> universal binders that agree up to the bound-variable renaming; here `Ax` is
> a body with the bound variable as a placeholder). The non-rectified Fig.-6
> `c∀` above is my reconstruction `S{∀x.∀x.A}/S{∀x.A}`; **verify against a
> clean copy of Fig. 6 before implementing the contraction phase.**

### 4.3 General contraction `c` (eq (3)) and derived rules

The general (non-atomic) contraction `c : S{A ∨ A} / S{A}` is **not primitive**
in KS1 — it is **derivable** (Lemma 25: `c ∈ {ac, m, m∨, m∃, ≡}`). Likewise
`w∀, c∀, m∨, m∃` are derivable from `{w, c, ≡}` (Lemma 26). KS1 keeps the
atomic/medial rules primitive precisely so contraction is *pushed down to
atoms* — this is what makes the decomposition (Thm 17) and the comb read-off
work. **Lemma 27:** `A ⟶{w,c,≡} B  ⟺  A ⟶{w,w∀,ac,c∀,m,m∨,m∃,≡} B`.

### 4.4 Rectified rules `c̃∀, m̃∀, m̃∃` (§IX)

`c∀, m∨, m∃` cannot be applied as-is when premise/conclusion must stay
rectified (they would collide bound variables). §IX defines rectified
variants used in the *rectified* resource derivation Φ̂2:

```
  c̃∀  S{∀y.∀x.Ax} / S{∀x.Ax}
  m̃∀  S{(∀y.Ay) ∨ (∀z.Bz)} / S{∀x.(Ax ∨ Bx)}
  m̃∃  S{(∃y.Ay) ∨ (∃z.Bz)} / S{∃x.(Ax ∨ Bx)}
```

where `x,y,z ∉ S{·}`, and `A·` is a body with a placeholder. In a rectified
premise `x=y`/`x=z` cases recover the un-tilded rules as special cases.

## 5. Decomposition normal form (Thm 16/17)

**Thm 16:** KS1 is sound and complete for first-order logic.

**Thm 17 (decomposition).** Every KS1 derivation `Φ : t ⟶ A` can be
reorganized into f-free formulas `A1,…,A5` and a derivation with the rules in
**fixed phase order** (top = `t`, bottom = `A`):

```
  t
  ║ {∀, ai, t}        ── axioms / units      ⎫
  A5                                          ⎪
  ║ {s, mix, ≡}       ── linear              ⎬  Φ1 = the MLS1^X "linear core"
  A4                                          ⎪      (= A5..A3 region, all MLS1^X)
  ║ {∃}               ── instantiation       ⎭
  A3
  ║ {m, m∨, m∃, ≡}    ── medial              ⎫
  A2                                          ⎪
  ║ {ac, c∀}          ── contraction         ⎬  Φ2 = the resource phase
  A1                                          ⎪      {w,w∀,ac,c∀,m,m∨,m∃,≡}
  ║ {w, w∀, ≡}        ── weakening           ⎭
  A
```

The split point for the bridge is `A' = A3` (`Φ1 : t ⟶ A'` is the whole
MLS1^X part = `{∀,ai,t}∪{s,mix,≡}∪{∃}`; `Φ2 : A' ⟶ A` is the resource part).
This is *stronger* than prior decompositions (atomic-contraction-only, or
contraction-only, or Herbrand-only). **Thm 18** is the weaker form actually
fed to the bridge: `Φ : t⟶A` ⟹ ∃ f-free `A'`, an MLS1^X proof of `A'`, and a
`{w,c,≡}` derivation `A' ⟶ A` (i.e. `A' = A3` above).

## 6. The bridge (Thm 19) — what we implement

### 6.1 KS1 → comb  (decomposed derivation ⟶ CombProof)   [critical path]

Input: a decomposed derivation as in Thm 17 / eq (6):
`t ─MLS1^X(Φ1)→ A' ─{w,w∀,ac,c∀,m,m∨,m∃,≡}(Φ2)→ A`.

1. **Rectify Φ1.** Transform `Φ1` into rectified `Φ̂1` proving `Â'` (§IX-A:
   each line of a rectified-conclusion MLS1^X derivation is rectified; rectify
   step-wise from conclusion to premise). The rectification determines a
   substitution `δΦ̂1` from existential bound vars to the terms the `∃`-rules
   instantiated them with — this is the **dualizer**.
2. **Read the fonet off Φ̂1 (Thm 33).** `[[Φ̂1]] = ⟨[[Â']], ∼Φ̂1⟩` is a
   **fonet** with dualizer `δΦ̂1`:
   - vertices = `[[Â']]` (the fograph of the linear core's conclusion);
   - **links `∼Φ̂1`** = the pairs of atom-occurrences that **meet in the
     instances of the `ai`-rule** in `Φ̂1` (each `ai : t / a∨ā` creates one
     link `{a, ā}`). *(Thm 19, observation (i).)*
   - **dualizer** `δΦ̂1` = the substitution collected from the `∃`-rule
     instances (`∃ : A[x/t] / ∃x.A` records `x ↦ t`). *(Thm 33 case 6.)*
   - Thm 33 proves this has **no induced bimatching** (via the "frame"
     construction, Lemma 34) ⟹ it is a genuine fonet.
3. **Read the skew bifibration off Φ2 (Lemma 40 + 41).** Rectify `Φ2` to
   `Φ̂2` (using `c̃∀, m̃∀, m̃∃`; Lemma 40). Its **induced map**
   `⌊Φ̂2⌋ : [[Â']] → [[A]]` is the vertex map built by composing the per-step
   induced maps (`⌊r⌋ : V_{[[Q]]} → V_{[[P]]}` — identity for `m,≡`; canonical
   injection for `w,w∀`; the two contracted atoms ↦ the one for `ac`; the two
   binders ↦ the one for the medials/`c̃∀`). **Lemma 41:** this map is a
   **skew bifibration** `[[Â']] → [[A]]`.
4. **Assemble.** `CombProof{ source = fonet from step 2, target = [[A]],
   fibration = ⌊Φ̂2⌋ from step 3 }`. Then `φ : C → [[A]]` with `C = [[Â']]`,
   which is exactly a FOCP (Def. 13). The existing `CombVerifier` re-checks it
   independently.

### 6.2 comb → KS1  (CombProof ⟶ decomposed derivation)   [oracle / test only]

Given `φ : C → A`, `A = [[A]]` (Thm 19 proof, §X):
1. Pick `C` with `[[C]] = C`, `ρφ` the induced renaming. **Lemma 43:** there
   is a resource derivation `Φ2 : Cρφ ⟶{w,w∀,ac,c∀,m,m∨,m∃,≡} A` (built from
   the skew bifibration via Lemmas 44 + 45).
2. `C` is a fonet, so **Thm 38** gives an MLS1^X derivation `Φ1' : t ⟶ C`
   (sequentialization: Thm 37 fonet→MLL1^X via the splitting-tensor theorem,
   then Lemma 20 MLL1^X→MLS1^X).
3. Apply `ρφ` to every line of `Φ1'` to get `Φ1 : t ⟶ Cρφ`; compose with `Φ2`.

We will build 6.2 only as far as needed to **cross-check** 6.1 on small cases
(round-trip: comb → KS1 → comb, or KS1 → comb verified by `CombVerifier`).

## 7. Build plan (math-first phases — spec → tests → impl → flip → commit)

Each phase follows `feedback-math-first-discipline`. New code lives in
`src/proof/ks1/` (the system) and `src/proof/translate/ks1_to_comb/` (the
bridge), mirroring `lkr/` and `translate/lkr_to_comb/`.

- **K0 — this doc.** Spec extracted from the paper. ✅ (commit it)
- **K1 — KS1 data structures + `≡`.** `ks1/formula` view with units `t`/`f`;
  context `S{·}` as a marked node / path; `≡` as a **normalize-modulo-eq(2)
  canonicalizer** + structural equality on the normal form (NOT raw fograph
  equality — see §2 K1 finding). Tests: `≡` reflexive/symmetric/transitive on
  eq-(2) instances; rectification idempotent; canonical form stable under
  operand permutation; agreement with fograph-isomorphism on small cases.
- **K2 — KS1 derivation + checker.** `Derivation` (top + steps), one validator
  per rule (§4). Independent of comb. Tests: each rule's redex/contractum
  accepted in-context and rejected off-pattern; replay the paper's Fig. 7
  example derivation of `(∃x.p̄x) ∨ (∀y.(py ∧ p̄fy))`; sound/complete sanity on
  a few small theorems (Thm 16).
- **K3 — decomposition checker (Thm 17).** A predicate "is this derivation in
  decomposed normal form?" + the split into `(Φ1, A', Φ2)`. (We can *require*
  decomposed input rather than implement the reorganization algorithm first;
  reorganization = a later phase if needed.) Tests: Fig. 7 splits at the
  phase boundaries; rule-out a derivation that violates phase order.
- **K4 — fonet read-off (Thm 33).** `Φ̂1 ⟶ comb::Fonet` (links from `ai`,
  dualizer from `∃`). Tests vs. `CombVerifier`: the produced fonet is valid
  (dualizer unifies links, no induced bimatching) on Fig. 4's four examples.
- **K5 — skew-bifibration read-off (Lemma 41).** `Φ̂2 ⟶ fibration` (induced
  map composition). Tests: the assembled `CombProof` passes `CombVerifier`
  end-to-end on Fig. 4's examples and on a small corpus theorem.
- **K6 — front end.** Decide ND→KS1 directly vs. LKR→KS1 vs. consume Track 1's
  cut-free LKR. The comb read-off (K4/K5) is front-end-agnostic; this phase
  feeds it real proofs and measures corpus coverage. **Cuts must be gone
  before this point** (Track 1 output or natively cut-free proofs).

**Obligation flip per phase:** a phase is done when its tests pass *and* the
next phase can consume its output unchanged. Update the roadmap checklist +
"Current state" (the roadmap is the living tracker; do not duplicate here).
